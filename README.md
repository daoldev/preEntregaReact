# 🍰 Tienda de Comida - Mercaditodeolaso

Esta pre-entrega contiene una SPA con React + Vite que muestra productos, permite ver detalles y sumar al carrito.

##🚀Despliegue en netlify: https://mercaditodeolaso.netlify.app/

## 🧭 Estructura importante
- `public/data/products.json` — datos de productos.
- `public/images/` — imágenes de productos (actualmente posee varias imágenes reales).
- `src/components/` — componentes: `Nav`, `ItemList`, `ItemDetail`, `Item`, `Header`, `Footer`, etc.

---

## 🚀 Cómo ejecutar
1. Instala dependencias:

```powershell
npm install
```

2. Levanta el servidor de desarrollo:

```powershell
npm run dev
```

3. Abre `http://localhost:5173/`
